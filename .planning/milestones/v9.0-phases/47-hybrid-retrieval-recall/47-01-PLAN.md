<objective>
Make the BM25-list fusion weight in the existing `rrfFuse` path a config-exposed tunable scalar (D-01/D-02). The cosine-list weight stays fixed at 1.0; the BM25-list weight becomes the single knob `bm25FusionWeight`. The config default is 0 (dark) — on the engine ranked path `weight=0` reproduces exactly today's pure-cosine behavior, mirroring the `bm25CandidateK=0` / `rankStrengthWeight=0` isolation convention.

This is the foundational mechanism change. It does NOT build fusion (Phase 17 already did) and does NOT yet flip the responder switch (that is Plan 03) or measure recall (Plan 02).

Purpose: give Plan 02 a single tunable scalar to sweep on held-out data, and Plan 03 a config default to ship.
Output: a tunable, isolatable BM25 fusion weight with a regression test proving `w=0` == pure cosine and that direct `hybridTopk` callers are unaffected.
</objective>
