<objective>
Add the auto-recede behavior — chrome fades to hairline ghosts on mouse-idle, during camera
flights, and when a node is focused/detail is open, and returns instantly on any mouse move —
using opacity-only transitions from the shared motion tokens. This needs two tiny additive state
exports (camera-in-flight, elapsed-since-active) plus a small opacity driver.

Purpose: D-08/D-09/D-10/D-11 — "the scene gets the stage exactly when you're watching it." The
recede feel is decoupled from the existing 1.2s scene-drift threshold (RESEARCH Pitfall 2) and
reuses the existing global mousemove listener (Pitfall 4 — no second listener).

Output: camera.js + stats.js one-line exports, hud-recede.js (new), app.js wiring, and the
opacity-only recede CSS classes.
</objective>
