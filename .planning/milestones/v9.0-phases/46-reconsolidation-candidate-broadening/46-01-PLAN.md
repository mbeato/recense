<objective>
Implement BM25 lexical candidate broadening in the OFFLINE consolidation sleep pass so the
contradiction-candidate set fed to the existing Sonnet judge becomes a union of
cosine top-k ∪ M1 entity/subject anchors ∪ BM25 (`node_fts` FTS5), instead of being gated
by cosine alone. Extend the auto-unrelated suppression gate so a BM25 lexical hit rescues a
low-cosine claim into judge escalation (the load-bearing D-04 change), add a `bm25CandidateK`
config knob (default 5, doubling as the `=0` isolation switch), and add observability counters.

Purpose: Today the PE-gated judge fires ZERO times on LongMemEval-KU contradictions because
contradicting facts embed at cosine ~0.48 and never clear the escalation gate. BM25 lexical
overlap rescues those claims into the judge. This plan delivers RECON-01 (union candidate gen)
and RECON-02 (union fed to judge with all guards preserved). Plan 46-02 measures the result.

Output: `bm25CandidateK` knob, the BM25 candidate source wired into consolidator.ts at the five
PATTERNS edit sites, D-06 counters, and two unit tests (isolation-switch regression + D-04 rescue).
</objective>
