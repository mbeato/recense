<objective>
Make per-prompt ambient recall (`retrieveRanked`) surface each retrieved seed's real 1-hop
`relation` graph out-edges as `hops` (score: null, rank-only), and carry each seed's real
cosine/RRF magnitude in the emitted seed payload (D-06). Today both `retrieveRanked` emit sites
emit `seeds: string[], hops: []`, so the viz almost never shows spreading-activation pathways on
ordinary recalls — only the rare curated path (`recall/index.ts:525`) does.

This is a read of edges that already exist, not a new retrieval algorithm. Nothing about what
`retrieveRanked` RETURNS to callers changes — this only enriches the fire-and-forget viz-trace
emit (T-10-05).

Purpose: satisfies SC1 (pathways light on every recall) with SC2/SC3 honesty (real edges, no
fabricated magnitude) machine-locked so it cannot silently regress.
Output: modified `src/retrieval/engine.ts` (both emit sites + named constant + shared helper) and
`tests/activation-trace-wiring.test.ts` (fixed seed assertions + new honesty guards).
</objective>
