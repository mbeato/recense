Current honest filter to extract (src/retrieval/engine.ts:391-418, buildAmbientTracePayload):
  - Input: seeds: Array<{ node_id: string; score: number }>
  - Per seed: store.getOutEdgesWithRel(seed.node_id) returns Array<{dst,rel,w,kind}>
  - filter e.kind === 'relation' && PRED_SET.has(e.rel)
  - .sort((a,b) => (b.w - a.w) || (a.dst < b.dst ? -1 : a.dst > b.dst ? 1 : 0))
  - walk in order; skip if store.getNode(edge.dst)?.tombstoned === 1 (liveness BEFORE slot, D-07 Pitfall 2)
  - de-dup on `${seed.node_id} ${edge.dst}` pair
  - stop when `taken >= topN`
  - push { node_id: edge.dst, src: seed.node_id, score: null, hop: 1 }
  - Output: { seeds (passthrough), hops }
