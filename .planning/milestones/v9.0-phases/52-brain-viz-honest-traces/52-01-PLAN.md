<objective>
Add the nullable row-level `kind` column to `activation_trace` (D-09) and thread it through the
`SQLiteActivationTraceSink` write path. This is the wave-1 foundation every downstream producer
(sleep-pass cascade, synchronous remember bridge) and the SSE consumer depend on. In the same
contract pass, widen `ActivationTraceInput.seeds` to the back-compat union so recall can carry a
per-seed score (D-07) — the seeds column is already JSON-serialized, so this is a type-only widening
the object-seed emitters in Plan 02 compile against.

Purpose: gives the viz a single row-level discriminator (`recall` / `new_node` / `reconsolidation`
/ `oscillation` / consolidation-neutral) AND a per-seed score channel on the EXISTING transport —
no new channel, no new table, no schema change for seeds (JSON text already holds either shape).
Output: migrated schema + sink that round-trips `kind` and both seed shapes, with tests pinning back-compat.
</objective>
