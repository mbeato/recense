gate can simply verify rather than police.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| graph node values → injected agent context | Stored text (some of it originally email-borne) rendered into the model's context window |
| renderer → token budget | An unbounded block is a cost and attention DoS on every turn |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-69-04-BUDGET | Denial of Service | injected block size | mitigate | `AMBIENT_BLOCK_CHAR_BUDGET` is enforced inside the renderer (hops dropped first), and the line count stays capped at AMBIENT_K. Asserted by unit test and re-verified over 58 real prompts by 69-06's gate. |
| T-69-04-FABRICATE | Repudiation | hop rendering | mitigate | Hops render only `rel` + a real neighbour node value from the engine's real out-edges; missing/tombstoned neighbours are dropped, and no score is printed because hop scores are `null` (WR-02). |
| T-69-04-SINK | Tampering | viz activation_trace | mitigate | The hop collector is a read-side consumer of the payload 69-02 already computes; Test 7 asserts trace rows are byte-identical with the knob on and off. |
| T-69-04-INJECT | Tampering | node text steering the agent | accept | Injected node values have always been rendered into context; this plan changes formatting, not the trust level of the content. Doc mode actually REDUCES injected untrusted body text to a title. Ingest-boundary sanitisation (Phase 62 EMAIL-03) remains the control. |
| T-69-04-CITE | Spoofing | `recense://doc/<id>` citation | mitigate | The URI carries the RAW node id with no transformation, matching the corpus layer's vocabulary, so a citation always resolves to the node actually surfaced — no prettified or guessed identifier. |
| T-69-04-DARK | Tampering | premature behavior change | mitigate | Both render modes are knob-gated dark; the byte-identity test from 69-03 must continue to pass. |
| T-69-SC | Tampering | package installs | mitigate | No installs. Net-zero new runtime dependencies. |
</threat_model>
