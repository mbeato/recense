<objective>
GAP-1: replace the fixed `CHART_W = 760` viewBox-stretch rendering with TRUE responsive
re-render. Measure the chart card's real pixel width at render time, render every chart at
that width so 1 internal unit == 1 rendered pixel (text and strokes stay at their designed
sizes at any window width), and re-render the active tab on a debounced window resize.

Purpose: the founder's UAT verdict (2026-07-11) — charts currently stretch like an image
when the window widens (fat strokes, blown-up text) because every SVG is
`viewBox="0 0 760 H"` + `width:100%` + `preserveAspectRatio="none"`. This is a locked
founder decision, not a suggestion.

Output: responsive chart rendering across BOTH tabs (Usage + Brain Health), a debounced
resize re-render backed by a per-tab data cache, and hover/marker interactions that stay
coordinate-correct at the new true width.
</objective>
