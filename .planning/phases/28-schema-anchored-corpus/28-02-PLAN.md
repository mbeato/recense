<objective>
Re-anchor the doc gather from a project scope-slug to a schema (D-09): add `gatherFactsForSchema(deps, params, opts)` alongside the existing `gatherFacts(deps, slug, opts)` in `doc-gather.ts`, and add a schema-thesis prompt framing to the generator so a schema-anchored doc reads as "this generalization is the thesis, its abstracted facts/entities are the evidence". Purpose: CORPUS-01 — a doc can anchor on a schema, not only a scope. The schema's `abstracts`-evidence is the spine (replacing `node_scope.scope = slug`); the schema member centroid seeds `hybridTopk` for semantic breadth (replacing `provider.embed([slug])` — the schema's induced label is often a weak `super:a + b + c` fallback, so the centroid is the faithful query vector and needs NO extra embed call); entity-hop re-roots at the schema's own abstracted entities.

Output: `gatherFactsForSchema` in `doc-gather.ts`; a schema-thesis generation path in `doc-generator.ts`; extended `doc-gather.test.ts`.
