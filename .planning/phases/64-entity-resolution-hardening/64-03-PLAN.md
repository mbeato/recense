<objective>
Wire the Phase 64 resolver into the sleep pass: two optional fields on the in-memory `ClaimDecision`, an `EntityResolver` instance on the `Consolidator`, and a resolution branch inside the existing per-episode loop that fires only for decisions already carrying intent fields.

The branch runs **strictly after** the `origin === 'inferred' || echoSourceId !== null || episode.source === 'hitl'` hard stop at consolidator.ts:660, inside the same iteration — inheriting that guard by construction rather than re-implementing it. This exact defect class (an independent scan that silently fails to inherit the guard) has shipped twice before in this codebase; Pitfall 6 and D-03 both name it.

Purpose: make the resolved entity available to Phase 65 without a DB schema change and without adding a single provider call.
Output: threaded, inert, observable resolution — plus the sentinel suite that proves each of those three words.
</objective>
