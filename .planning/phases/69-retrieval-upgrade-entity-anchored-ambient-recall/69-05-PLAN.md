<objective>
Give `recense recall` a verifiable output mode: cited node ids plus the edges actually
traversed, read-only and LLM-free, so an agent can confirm a memory claim without grepping.

Purpose: the audit's 43%-still-grepping number has a mechanical cause — grep output is
verifiable and composed prose isn't. Evidence mode is the direct attack (SC4/D-07). It is
independent of the ambient pipeline, so it ships in wave 1 alongside the anchoring work.

Output: an optional `evidence` mode on `RecallEngine.recall`, a `--evidence` CLI flag, and
tests proving zero generates and zero writes.
</objective>

|-----------|----------|-----------|-------------|-----------------|
| T-69-05-WRITE | Elevation of Privilege | evidence branch writing to the graph or episode log | mitigate | No `episodes.append`, no `upsertNode`/`upsertEdge`/`strengthen`/`tombstone`, no trace emit under `opts.evidence`; row-count assertions plus a same-line source guard enforce it (D-07, D-43). |
| T-69-05-FABRICATE | Repudiation | cited edges that were not traversed | mitigate | Edges are captured from the traversal structures already in memory (typedFrontier / `abstracts` / `schema_rel` walks), never re-derived or inferred; the insight branch — which has no traversal to cite — is skipped rather than described. |
| T-69-05-PARSE | Denial of Service | caller `JSON.parse(stdout)` on an early exit | mitigate | `SAFE_NULL_EVIDENCE_RESULT` is written at every early exit under `--evidence`, preserving the file's always-parseable-JSON discipline (WR-03). |
| T-69-05-I | Tampering | query string reaching SQL or a shell | mitigate | Inherited T-04-03-I: the query is embedded and used as prompt data only; in evidence mode it never reaches a prompt at all. No new SQL, no interpolation. |
| T-69-05-DISCLOSE | Information Disclosure | evidence exposing node ids | accept | Single-tenant, local CLI, operator-invoked; node ids are already surfaced by the corpus/citation layer and the viz. No new exposure surface. |
| T-69-05-K | Information Disclosure | API keys in output/logs | mitigate | Unchanged: provider names only are logged (T-04-03-K / T-05-02-KEY); evidence mode adds no logging. |
