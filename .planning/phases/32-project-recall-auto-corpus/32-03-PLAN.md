Wire the scope-anchored always-promote (built in Plan 32-02) into BOTH ingest trigger paths (D-03),
using a crash-safe meta marker for the deferred path (D-05).

- Inline (`--consolidate`, ingest-project-cli.ts ~:728): after `runConsolidation`, while the lock is
  still held, force-promote the project scope (CorpusPromoter.promoteScope) and run
  generateCorpusDocs so the project's landing doc + chapter docs are generated before the command returns.

  to SemanticStore meta (same plumbing as `cursor:project:<scope>`), then return LLM-free as today.

  scope, then run the existing generateCorpusDocs to fill the stubs; clear each marker only AFTER its
  force-promotion succeeds (crash-safe — a crash leaves the marker so the next pass retries).

the project's corpus is auto-promoted AND generated, browsable in the Reader with no separate step.
