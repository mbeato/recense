<objective>
Add a `--scope <slug>` provenance filter to `recense recall` (RECALL-01). A scoped recall
returns only the named project's knowledge plus cross-cutting `global` facts, excluding all
other named projects (D-01). The filter is applied AFTER schema resolution / neighborhood
assembly and NEVER feeds ranking or scoring — scope is provenance, not a retrieval signal
(D-S1, locked at 999.3).

Purpose: gives the founder an instant project-scoped view (SC1) over the live brain — e.g.
`recense recall "architecture" --scope usage` surfaces only the `usage` project (+ global).
Output: a `--scope` flag on the CLI, threaded to `RecallEngine.recall()`, plus a post-resolution
member filter and a test suite proving the {slug, global} semantics and the D-S1 ranking guard.
</objective>
