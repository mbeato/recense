<objective>
ISOLATE the duplicate-fact failure before fixing it (D-02). The V3 diagnosis localized the
bug to **post-retrieval** — the surfaced near-dup pairs (cosine 0.7–0.97) all reached the
candidate set yet were minted as separate nodes — but a read-only embedding probe cannot see
the judge verdict. This plan runs a **judge-replay** over the ~30 surfaced near-duplicate
claim/candidate pairs, reads the live judge verdicts, and recomputes PE routing, to split the
failure into:

  (a) **judge-misclassify** — the judge returns `unrelated`/`extend` for a same-belief
      restatement (should have been `confirm` or `contradict`), OR
  (b) **PE-routing-escape** — the judge returns `contradict` but `routeContradiction` chooses
      `append-new`/`hold` instead of `reconcile` (governed by `peReconcileBandLow`,
      `peReconcileBandHigh`, `peAppendNewMinResistance`).

The output of this plan **drives the 26-07 fix** — do NOT fix blind. If (a) dominates, 26-07
targets `src/model/judge.ts` (prompt / classification). If (b) dominates, 26-07 targets the
PE-routing constants in `src/lib/config.ts` and/or `routeContradiction` logic.

src/model/judge.ts:
  - export type JudgeRelation = 'confirm' | 'extend' | 'contradict' | 'unrelated'
  - export interface JudgeVerdict { best_candidate_id; relation; magnitude; contradicted_ids[] }

  - SAFE_VERDICT fallback = { relation: 'unrelated', magnitude: 0, ... } on malformed JSON

src/consolidation/update-decision.ts:
  - export function routeContradiction(peMagnitude, resistance, config): 'hold'|'reconcile'|'append-new'
    ratio = peMagnitude / max(resistance, EPS)
    ratio < peReconcileBandLow → 'hold'
    ratio < peReconcileBandHigh → 'reconcile'
    ratio >= peReconcileBandHigh AND resistance >= peAppendNewMinResistance → 'append-new'
    ratio >= peReconcileBandHigh AND resistance <  peAppendNewMinResistance → 'reconcile'
  - resistance = effectiveStrength(node) * node.c  (D-16)

src/lib/config.ts §257-293 — DEFAULT_CONFIG values:
  - unrelatedSimilarityThreshold 0.3 (candidate gate — NOT the lever)
  - peReconcileBandLow 0.8, peReconcileBandHigh 2.0, peAppendNewMinResistance 0.3
  - the §278-293 comment documents this exact failure class
