<objective>
Build the **fact-level dedup/reconciliation pass** (RETR-03) — the residual cleanup track that
collapses the real duplicate `type='fact'` nodes already in the live graph (the 26-06/V3 fix
is prevention; this is remediation of what already accumulated). It generalizes Phase 25's
`EntityDedup` engine to fact nodes: cluster near-duplicate live fact nodes, select a canonical,
rewire all edges, **tombstone the losers (never delete)**, preserve provenance, stay FK-clean,
and be repeatable (second run = no-op).

Critically (D-05), it must **EXCLUDE known `claude-headless` self-ingestion pollution** —
`SUBCHECK_OK` tokens and "Task … exit code 0" / "completed with status" artifacts — from the
"real duplicate" set, so the count is not inflated by garbage (the V3 152-pair count was
inflated by exactly these).

The CLI is opt-in with `--dry-run` as the DEFAULT, mirroring the Phase 25 `dedup-entities` CLI
(`autonomous: false` for the real-write run, like 24-03). It is NOT wired into the hourly sleep
pass.
</objective>
