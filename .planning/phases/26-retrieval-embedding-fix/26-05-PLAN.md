Build the **extraction-replay KU harness** (`scripts/eval/replay-ku-harness.cjs`) that
RETR-02 validates against (D-04). It consumes the cached granite extractions
(`~/.recense-eval-cache/eval01-n20-2026-06-16/`, 39,914 claims) and re-runs
embed → consolidate → retrieve → score WITHOUT re-extracting from granite (avoids the
~45h extraction cost). The harness was specced in the now-superseded 26-02 plan but never
executed, so it must still be built.

embedder swap is performed here (the swap is a falsified/deferred premise, D-01). Its
load-bearing output is **judge-engagement**: tombstone count, contradict-verdict count, and
duplicate-minting count, because a KU-score bump alone does not prove the belief-correction
mechanism fired (the diagnosis showed correct answers can come from extraction + recency).

Purpose: 26-07 cannot prove "duplicate-minting measurably reduced AND EVAL-02 belief-
correction not below 84.6%" without this harness.
