<objective>
RETR-03 + the coupled fix: swap the live embedder to `text-embedding-3-large`
(kept at 1536 dims via the `dimensions` param, D-05), add the v11 `embedding_model`
meta stamp (D-08) so a future model change auto-invalidates the vector cache, and
ship an opt-in `recense reembed` CLI (dry-run default) that nulls all embeddings —
including `tombstoned=1` rows (D-06, D-29) — re-embeds every node through the single
writer `setEmbedding`, and stamps the new model.

These land together because they are coupled: a model swap without a re-embed leaves
a stale vector cache in a different vector space (graph stays source of truth; the
vector store is derived and must be rebuilt). The CLI is opt-in/dry-run-default;
running it against the live DB is the founder-gated Plan 04.

Purpose: RETR-03 — any embedder change re-embeds stored node texts and rebuilds the
derived cache consistently; graph stays source of truth, no node deleted.
Output: config swap + v11 stamp + `reembed-cli.ts` + dispatcher wiring + unit test.
