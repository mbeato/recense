<objective>
Close CR-01 and CR-03 by giving the module one opinion about which elements are special, and close
WR-01 with the same source.

Purpose: `62-VERIFICATION.md` records both blockers as the SAME failure mode, the one this phase has
now hit seven times: *two parts of the module hold different opinions about one boundary, and the
argument that they agree lives in prose.*

- **CR-01**: `scanHtml` marks a `<style>` whose raw text ends `/>` as `selfClosingSyntax` (`:663`) and
  excludes it from `styleElements` (`:694`, `:732`), while `collectStartTagRemovalRanges` +
  `NON_CONTENT_TAGS` (`:1576-1579`) delete the element unconditionally. The stylesheet is deleted and
  the elements it hides are not, so `<style/>.legal{display:none}</style>ok<span class="legal">PAYLOAD</span>`
  emits `"okPAYLOAD"` — confirmed end-to-end through `normalizeGmailMessage`. The comment justifying
  the exclusion (`:695-698`) cites a stage-4 treatment that 62-24 DELETED; `SELF_CLOSING_SUFFIX_RE`'s
  only remaining consumer is `:663` itself. RAWTEXT elements are never self-closable by syntax (HTML
  §13.2.5 — this module's own conformance gate asserts it at `tests/html-parser-conformance.test.ts:283`).
- **CR-03**: `RAWTEXT_CLOSE_SLASH_RE` (`:593`) enumerates eight raw-text names; `NON_CONTENT_TAGS`
  (`:1225-1227`) is a DIFFERENT hand-maintained seven that omits `iframe`, `noembed`, `noframes`. Their
  fallback text — rendered by no browser, stripped by Gmail — is emitted verbatim.
- **WR-01**: `harvestHidingSelectors` consumes every `styleElement` regardless of whether a browser
  would ever apply that stylesheet, so a `<style>` written inside `<iframe>`/`<noscript>` deletes prose
  the recipient DOES see.

The fix is not a third list and not a fourth comment asserting the lists agree. It is one keyed
disposition map that every consumer derives from, with a compile-time exhaustiveness check.

Output: `<style/>` harvested, `iframe`/`noembed`/`noframes` contents deleted, never-applied
stylesheets not harvested, and a source that cannot silently diverge again.
</objective>
