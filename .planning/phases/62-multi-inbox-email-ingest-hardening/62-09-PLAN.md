<objective>
Close the fourth instance of the CR-01 bug class. Plan 62-07 made `START_TAG_RE`, `ANY_TAG_TOKEN_RE` and
`ANY_TAG_RE` quote-aware but enumerated "all three tag regexes" when the file contains **four**
attribute-scanning regexes. `STYLE_BLOCK_RE` (`src/source/strip-hidden.ts:201`) still uses the pre-fix `[^>]*`
attribute class, so when a `<style>` open tag carries a quoted attribute value containing a literal `>`, the
match terminates mid-attribute, `styleMatch[1]` starts mid-attribute, `RULE_RE` sees a garbage selector,
`allBare` fails, **nothing is harvested**, and stage 5 never learns the class is hidden. Stage 4 — which IS
quote-aware — then deletes the whole `<style>` element correctly, so the hiding rule is destroyed *and* never
recorded, and the payload reaches `record.content` as ordinary prose.

reproduced by the verifier against the shipped `dist/` build, and re-reproduced during planning of this plan
