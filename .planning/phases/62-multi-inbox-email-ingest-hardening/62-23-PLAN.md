<objective>
Make the documented `src/` isolation guard real, and prove it.

Purpose: `src/types/css-tree-tokenizer.d.ts:10-16` states that an import of the bare `css-tree`
package from a file under `src/` "fails to compile, since no ambient declaration exists for that
import path from `src/`'s perspective." `62-VERIFICATION.md` disproved this by construction: a probe
under `src/source/` importing both the bare `css-tree` package and the test-only liveness oracle
compiled cleanly (`npx tsc --noEmit`, exit 0), because `declare module 'css-tree'` in
`tests/support/css-tree-ambient.d.ts` is a PROGRAM-GLOBAL ambient declaration and `tsconfig.json`'s
`include` is `["src","tests","scripts"]`. Both halves of invariant T-62-17-08 fail, and the only
enforcement anywhere is a one-shot grep embedded in a planning document.

This matters beyond tidiness: the oracle is the phase's independent ground truth. An oracle
reachable from production is an oracle that can be made to agree with production — the exact
circularity WR-09 named as this phase's root cause.

Output: a tests-scoped TypeScript project, corrected documentation, and a shipped, non-vacuous
regression lock.
</objective>
