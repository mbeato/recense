<objective>
Extend the live Phase-30 `recense ingest-project <dir>` command so a single run ingests the project's OWN documents (README.md, CLAUDE.md, docs/**/*.md) as episodes — in addition to the agentic survey — without configuring an Obsidian vault. This delivers DOCING-01.

Doc episodes reuse the Obsidian helpers (`chunkNote`, `redactSecrets`, `contentExternalId`) but invert origin to `'observed'` and tag `source='project-doc'`. They route through the same `pipeline.recordEvent` path as survey episodes. Per-file content-hashing (`contentExternalId(relPath, content)`) gives the doc path edit→reconcile and unchanged→near-no-op idempotency for free.

Purpose: Onboarding stays one action (D-01) and now captures the project's authored knowledge, not just the agent's survey.
Output: A `emitDocEpisodes` helper + its wiring in both real-run branches of `main()`, plus doc-emit unit tests.

This plan does NOT touch the cursor / re-survey gating (that is Plan 02). It only adds doc emission, which is independently idempotent via content-hash.
</objective>
