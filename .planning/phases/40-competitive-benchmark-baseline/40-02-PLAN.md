<objective>
Build `scripts/eval/locomo-harness.cjs` as a clone-and-adapt of `longmemeval-harness.cjs`: load the LoCoMo-10 JSON array, run per-conversation ingest (one episode per session, tagged `[Session N]`), consolidate ONCE per conversation, then loop every non-adversarial QA pair — embedding the question, timing retrieval-only `CandidateRetriever.topk`, computing a session-level R@K hit, and (outside dry-run) generating a Haiku answer. The harness is gated `--dry-run` / `--probe` / `--run` so an autonomous executor can validate it cheaply but cannot trigger a paid full run.

Purpose: BENCH-01 (reproducible LoCoMo harness) + the retrieval-latency and R@K halves of BENCH-02. This is the engine that the scorer (Plan 03) and the official run (Plan 05) consume.
Output: `locomo-harness.cjs`, un-skipped harness unit tests.
