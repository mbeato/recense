<objective>
Restructure the index sidebar from a flat indented wall of text into an Obsidian/VS-Code-style
collapsible tree (D-01) and rewire project-row clicks to focus the graph (D-03). Projects render
collapsed by default with a chevron + doc-count; expanding reveals docs in place. This is the
wall-of-text half of founder defect D1 and the index-side half of the D2 browsing flow.

Purpose: The current renderTreeSection emits every entry flat-with-indent, so all docs are always
visible — the "huge thing of text" defect. Gating child emission behind an expanded Set fixes it.
Output: One edited file — index.js — reusing its own tree-walk + filter-ancestor logic, changing
only the render (flat -> collapsible) and the project-row click handler.

Depends on Plan 02's hook contract:
- ctx.focusCorpusProject(scope | null) — project-name click focuses the cluster.
- ctx.setCorpusProjectExpanded(scope, expanded) — chevron toggle reveals/hides that project's chapters.
For BOTH hooks the `scope` argument is the project-root row's `entry.slug` (see the SCOPE ARGUMENT note
in interfaces below — this is the load-bearing contract for the whole D2 browse flow).
Depends on Plan 01's CSS classes: .index-row, .index-chevron (+ .expanded), .index-count.
</objective>

SCOPE ARGUMENT (load-bearing — do NOT get this wrong):
- The scope passed to ctx.focusCorpusProject / ctx.setCorpusProjectExpanded MUST be the project-root
  row's `entry.slug` (e.g. 'vtx'). The /index endpoint's Entry type is exactly
  `{ slug, label, id, parentId, depth }` (server.ts:1314) — there is NO `scope` field. Writing
  `entry.scope` yields `undefined`, and both corpus hooks guard-ignore an invalid/absent scope, so the
  click would SILENTLY do nothing (this is the phase's central deliverable — founder defect D2 — so a
  silent no-op is a hard failure). The invariant that makes `entry.slug` correct: a project-root slug
  has no ':', so its node_scope.scope = rootScope(slug) = slug (doc-writer.ts:192), which is exactly
  the project scope corpus.js validates against projectScopes.

Plan-02 hooks (owner: corpus.js) consumed here via guarded call, same style as ctx.highlightCorpusNode/openReader:
- ctx.focusCorpusProject(scope | null)     // scope = project-root entry.slug
