<objective>
Rebuild the corpus 2D graph's browsing behavior: project focus with dim-others (D-04), graph-hover
subtree + dim parity (D-05), tiered labels to kill the pile-up (D-06), and focus-driven chapter
visibility replacing the deleted toggle button (D-07). Land the cross-module hook contract
(`ctx.focusCorpusProject`, `ctx.setCorpusProjectExpanded`) that Plan 03's index tree consumes.

Purpose: This is founder defects D2 ("browsing experience broken") and D3 ("clutter / labels on
top of each other / flat hover"). All three D3 complaints and the D2 focus flow live here.
Output: constants.js (4 new named tunables) + corpus.js (focus state machine + paint-time dim/label
tiering + deleted chapter toggle + 2 new ctx hooks + Esc/background-click exit).

CONTRACT (Plan 03 depends on this — define these exactly):
- `ctx.focusCorpusProject(scope | null)` — focus a project's cluster (zoom + dim others, reveal its
  chapters) or, with `null`, exit focus. The `scope` argument is a project-ROOT slug (e.g. `vtx`) —
  index.js passes `entry.slug` of the project-root row. Ignores a scope not present in `projectScopes`.
- `ctx.setCorpusProjectExpanded(scope, expanded)` — reveal/hide that project's chapter docs in the
  graph WITHOUT zooming or dimming (drives the "tree row expanded → chapters visible" half of D-07).
  Same `scope` = project-root slug contract.
</objective>
