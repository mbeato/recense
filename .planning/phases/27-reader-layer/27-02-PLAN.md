<objective>
Build the doc-generation core (READER-01): gather a project's facts (scope ∪ semantic ∪ entity-hop, D-01), generate a cited markdown deep-dive via the judge-tier model (D-04, NO new docModel var), verify every citation resolves, and write the result as a LIFECYCLE-EXEMPT `type='doc'` node through the single-writer store (node + node_doc sidecar + node_scope + `cites` edges in one transaction). <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored fact text → LLM prompt | ingested-episode fact values (untrusted origin) are concatenated into the generation prompt → prompt-injection surface |
| generate CLI → live DB | the only write path for doc nodes; a buggy run could mutate facts or run unbounded LLM spend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-03 | Tampering (prompt injection) | doc-generator prompt built from fact values | mitigate | The verbatim slice prompt hard-rules "use ONLY provided facts; cite every claim or omit it" — injected instructions in a fact value cannot add uncited claims because the citation-verify loop drops any claim/id not resolving to a real fact node; generated prose is never executed, only rendered (XSS handled in 27-03). |
| T-27-04 | Spoofing/Tampering | invented citation ids | mitigate | Citation-verify loop excludes any recense://fact/<id> with no live node from cites edges and reports invented count; checkpoint asserts invented=0. |
| T-27-05 | Elevation / self-confirmation (D-43) | doc generation reading facts | mitigate | doc-writer never calls strengthen/setEmbedding/markActive on cited facts; gather is read-only; doc node origin='inferred' so it cannot become training-eligible — generation cannot bump a cited fact's salience/last_access. |
| T-27-06 | Denial of Service (LLM spend) | generate CLI | mitigate | One generate call per invocation (maxTokens 4000); idempotent (existing doc → no LLM call unless --force); lazy/low-volume per D-06. No auto-batch. |
| T-27-07 | Tampering | write path bypassing single-writer | mitigate | All doc writes route through SemanticStore primitives inside one IMMEDIATE transaction + the shared writer lock (acquireLock); CLI grep gate asserts no raw node/edge SQL in doc-writer. |
| T-27-SC | Tampering | npm/pip/cargo installs | accept | Net-zero new runtime deps (invariant); no install tasks → no audit table required. |
</threat_model>
