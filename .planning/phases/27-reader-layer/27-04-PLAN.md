<objective>
Deliver citation staleness (READER-03): a `GET /doc/staleness?slug=` endpoint that, for each cited fact, compares `node.last_access > node_doc.generated_at` and flags tombstoned cited facts; a top-of-doc banner summarizing changes with a regenerate CTA + inline markers on changed/tombstoned refs (D-10); a `prev_value → value` diff shown in the existing atom panel when a stale ref is clicked; and a regenerate action (POST /doc/generate --force) that rebuilds the doc from current facts. Whole-doc regen only — section-level regen is v2 (READER-05, out of scope).

Purpose: docs are generated snapshots; the data layer is always live (ids, not copied text), but the prose display text can drift. READER-03 surfaces that drift honestly and offers one-button reconciliation.
Output: staleness endpoint, banner + inline markers, atom-panel diff, regenerate wiring, staleness tests, human-verify checkpoint.
</objective>
