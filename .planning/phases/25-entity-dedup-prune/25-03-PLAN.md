<live_db_notes>
- Live DB: `~/.config/recense/recense.db`. The CLIs resolve it via RECENSE_DB env (set in
  `~/.config/recense/sleep.env`) or a `--db` flag. Source env the same way a manual sleep pass does:
  `set -a; . ~/.config/recense/sleep.env; set +a`.
- The hourly `com.recense.sleep-pass` agent shares the lockfile — run dedup while it is idle, or the
  mutating run will exit on a held lock (by design).
- Distinct "brain-memory" entity count is read with: `SELECT COUNT(*) FROM node WHERE type='entity'
  AND tombstoned=0 AND lower(value) LIKE '%brain-memory%';` (the canonical node survives; tombstoned
  duplicates are excluded by `tombstoned=0`).
- FK status: `PRAGMA foreign_key_check;` must return zero rows.
</live_db_notes>
