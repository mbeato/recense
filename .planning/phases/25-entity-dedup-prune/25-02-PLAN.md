<objective>
Ship the opt-in `recense dedup-entities` CLI subcommand wrapping the EntityDedup engine from
Plan 01. The CLI defaults to a `--dry-run` report (clusters it would merge, counts, sample) and
only mutates when explicitly run without `--dry-run`. It is NOT wired into the hourly sleep pass
(D-11) — a separate, manual, founder-invoked command, mirroring the "gated live-write needs a real
off-switch" lesson.

Purpose: Give the founder a safe, inspectable front door to the dedup pass. Dry-run-first means the
real merge (Plan 03) is always preceded by a printed plan the founder reviews.

Output: `src/adapter/dedup-entities-cli.ts`, a `dedup-entities` case in the recense dispatcher, and a
CLI-level test asserting the dry-run path writes nothing.
</objective>
