## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-05 | Tampering / data integrity | live-brain pollution | mitigate | `--dry-run` (D-05) runs the full survey and prints per-area would-be episodes writing 0 rows; the resolved scope is printed before any write (D-09) — operator safety valve against polluting customer-zero. |
| T-30-06 | Tampering | self-confirmation of beliefs | mitigate | Every episode is `origin:'observed'` (never `asserted_by_user`/`inferred`) so survey output can never strengthen/self-confirm an existing belief (CLAUDE.md invariant). Asserted in a unit test. |
| T-30-07 | Tampering | apology/refusal text ingested as fact | mitigate | `isRefusalOrToolFailure` gate (Plan 01) blocks refusal/tool-failure responses before ingest; retry-once-then-skip (D-07). Asserted in a unit test. |
| T-30-08 | Denial of Service | write-lock contention with live hourly pass | mitigate | Default path holds NO lock (deferred sentinel handoff, D-01). `--consolidate` uses the real global lock intentionally and fast-fails (no queue) if the hourly pass holds it. |
| T-30-09 | Information disclosure | scope mis-attribution | mitigate | `--scope` threaded via synthetic home-rooted cwd so facts land under the intended `[scope]`; resolved scope printed before write so mis-scoping is caught by the operator. |
| T-30-SC | Tampering | npm/pip/cargo installs | accept | Net-zero new runtime deps (engine invariant); `package.json` unchanged. No install tasks → no Package Legitimacy Gate. |
