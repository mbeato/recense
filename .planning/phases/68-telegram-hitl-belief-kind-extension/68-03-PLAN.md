## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram callback_query → client | `callback_data` is attacker-influenceable; the allowlist authorizes the sender, not the payload |
| client → recense serve (authenticated POST) | A Bearer-authenticated state change on the memory graph, triggered by a button tap |
| client → memory (audit episode) | The audit write is an ingestion path back into the system being audited |
