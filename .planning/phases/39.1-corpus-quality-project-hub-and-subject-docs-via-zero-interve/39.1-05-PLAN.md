## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ingest-project survey → live brain | Bulk write of survey episodes + bulk doc generation against the live, unbacked brain |
| bulk drift event → exhaust-gate | A large fresh ingest can open many gates at once — token-cost surface |

This plan adds NO new code and NO new network/auth surface; it invokes existing CLIs. The material risks are (1) a token/cost blowout from the bulk drift event and (2) noisy survey output producing junk subjects.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39.1-16 | Denial of Service | bulk-ingest opening many CREATE gates at once | mitigate | RECENSE_CORPUS_GEN_MAX budget cap (Plan 03 / D-07) bounds docs per pass; overflow deferred to the self-draining queue — verified in Task 2 acceptance |

| T-39.1-18 | Information Disclosure | vtx content ingested into the recense brain | accept | Single-tenant local brain; vtx is the founder's own project; intentional dogfood scope tagging |

No package installs. No deletes (cleanup was Plan 04). Real OpenAI embedding spend is the only $-cost surface — gated by the Task 1 cost check.
