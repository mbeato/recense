<objective>
Replace the reader's pure time-estimate bar with a phase-aware stepper driven by the server's
202 envelope, and DELETE the `prevGeneratedAt`/`fetchGeneratedAt` silent-no-op hack. The stepper
renders the named phases (queued/gathering/generating/verifying/finalizing) with the active one
highlighted and a live elapsed clock; the `generating` phase keeps the exponential time-estimate
fill (the only phase worth estimating), the others are discrete check-off steps. The poll loop
reads `phase`/`error`: `phase:'failed'` stops polling and shows the real reason via `textContent`
(T-10-12 — never innerHTML a DB/error string). The authoritative `failed` phase from the envelope
replaces the generated_at comparison.

Purpose: RGS-01 (named phases surfaced, pure-estimate bar gone) and RGS-03 (authoritative failed
phase replaces the silent-no-op hack; generic "timed out or errored" string removed).

Output: phase-aware `startGenProgress`, phase/error handling in `loadWithPoll`, deleted hack in
`regenerate()`/`fetchGeneratedAt`, and minimal stepper CSS.
</objective>
