## What Was Built

**src/viz/server.ts** — two targeted changes:
1. Added import of `readStatus` and `buildGeneratingEnvelope` from `../adapter/gen-status` (alongside existing settings-loader import)
2. Updated `send202Generating` to call `readStatus(slug)` then build the 202 body via `buildGeneratingEnvelope(st, elapsedMs)` — the helper is the single gate for key-presence, so `error: undefined` / `phase: undefined` can never appear in the serialized JSON

`elapsedMs` derivation from `inFlightSlugs` is unchanged. The DB handle stays `{ readonly: true }` (T-27-11, T-39.3-06). `spawnGenerateDoc` is untouched.

**tests/gen-envelope.test.ts** — 13 tests covering 3 cases:
- (a) failed status: `phase:'failed'` + `error:'engine stayed busy'` both present; `toMatchObject` assertion on exact shape
- (b) null status: `'phase' in env === false` and `'error' in env === false`; `JSON.stringify` does not contain `"error"` substring
- (c) gathering status: `phase:'gathering'` forwarded; `'error' in env === false`
