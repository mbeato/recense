## What Was Built

`src/adapter/gen-status.ts` — leaf module (no imports from src/reader, src/viz, src/consolidation) that provides:

- `PHASES`: frozen array of 7 locked generation phases (queued → failed)
- `statusPath(slug)`: maps any slug to `/tmp/recense-gen-status/<sha1.slice(0,16)>.json` — path-traversal-safe by construction
- `writeStatus(slug, phase, extra?)`: atomic temp-then-renameSync write of `{phase, startedAt, updatedAt, error?}`; preserves `startedAt` across transitions for the same slug
- `readStatus(slug)`: returns parsed GenStatus or null (missing / malformed / stale > 15min)
- `clearStatus(slug)`: unlinks file; no-op (ENOENT) when absent
- `buildGeneratingEnvelope(status, elapsedMs)`: pure function returning `{status:'generating', elapsedMs}` plus conditional `phase` and `error` keys — never emits `phase:undefined` or `error:undefined`

`tests/gen-status.test.ts` — 20 tests covering:
- PHASES contents + frozen invariant
- statusPath determinism + traversal-safety (`../../etc/passwd`, `a/b/c`)
- writeStatus→readStatus round-trip: phase, timestamps, startedAt preservation across transitions
- Error field write + read
- Staleness: back-dated updatedAt → null
- clearStatus: removes file; no-op on missing slug
- buildGeneratingEnvelope: 3 key-presence cases (null status, failed+error, non-failed)
